## GeoMine Explorer v1.0.0 Release Notes

GeoMine Explorer is a lightweight, zero-dependency Windows desktop application built for exploration geologists, mining engineers, and resource estimators.

### 🌟 What's Included
- **Standalone Windows Executable**: `GeoMineExplorer.exe` (~115 KB) - no Python, Java, or .NET runtime installation required. Runs directly on Windows 10 & 11.
- **Packaged Release ZIP**: `GeoMineExplorer-v1.0.0-windows-x64.zip` containing the executable, documentation, and sample datasets.
- **Built-in Sample Exploration Project**: Preloaded with the *Golden Ridge Au-Cu* project data for instant testing.

### 🛠️ Core Features
1. **Drillhole Data Management**: Tabular data inspection for Collars, Surveys, Assays, Lithologies, and Structures with CSV import/export.
2. **Interactive Graphic Strip Log**: Downhole visual logging with depth ruler, colored lithology segments, assay grade histograms, and interactive hover crosshairs.
3. **Plan Map & Cross-Section Projection**: Minimum Curvature & Balanced Tangential desurveying algorithm with azimuth and corridor tolerance slicing.
4. **Assay Statistics & Cut-off Grade Calculator**: Descriptive statistics, Grade-Thickness ($GT$) calculation, and grade frequency histogram with cumulative % curve.
5. **Downhole Length-Weighted Compositing**: Composite interval calculation preserving in-situ weighted grades with CSV export.
6. **Structural Geology & Section Calculator**: Strike/Dip to Dip Direction converter (RHR), Apparent Dip on sections, True Stratigraphic Thickness calculator, and 360° Polar Rose Diagram.
7. **Mine Resource & Tonnage Estimator**: Quick volume, tonnage, contained metal, and gross metal value estimator with sensitivity analysis.

### 📥 Download & Usage
Download either `GeoMineExplorer-v1.0.0-windows-x64.zip` or the standalone `GeoMineExplorer.exe` below, double-click, and start exploring!
